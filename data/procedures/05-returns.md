## Request a return review
For a return request, record the delivery identifier, reason, and affected package count, then request a return review. Keep the packages available for inspection by the fictional quality coordinator. A recorded return request is not return authorization. Do not dispatch packages back until the fictional coordinator has provided return instructions.
